# Marketing agent skills archive

A snapshot of 813 marketing-focused agent skills (`SKILL.md` files) catalogued by
[skills.marketing](https://skills.marketing), collected on 2026-10-20.

## Attribution and licensing

I did not write these skills. Each one belongs to its original author and stays under the license
that author chose (mostly MIT and Apache-2.0). For every skill:

- `skills/<name>/SKILL.md` is the file as published in the source repository.
- `skills/<name>/meta.json` records the source repository, the exact source file, and the license.
- `licenses/<owner>--<repo>.txt` is the upstream license text (171 of 171 repos had a license file at the root).

Skills with no license declared upstream are not copied here. They are listed as links in
[INDEX.md](INDEX.md). If you are an author and want your skill removed, open an issue and it goes.

Start with [INDEX.md](INDEX.md) or [index.csv](index.csv).
